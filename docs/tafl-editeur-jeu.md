- Agreed 2026-10-20 (thread "Tafl éditeur de jeu"): Tafl describes the game as data, a separate engine tool (built later, own thread) runs it. See [tafl](tafl.md).
- Proposed format: one game folder = jeu.json + tuiles.tafl (shared tileset) + cartes/*.json (calques, passage grid libre/bloqué/rebord with per-tile default, zones rects, teleporteurs, evenements) + donnees/*.json + sprites/ + FORMAT.md; "format": 1 version field; scripts = JSON command lists (dire, donner, si, teleporter…). Keep Tiled .tmj export.
- Steps: 0.6 game folder + multi maps + passage/zones/warps/start; 0.7 events + switches; 0.8 databases + encounter tables; then engine + Jouer button.
- Ragna's game wishlist (2026-10-20) mapped into the format: donnees/personnages.json (portraits per expression, speaking hero, rivals, hero outfits), donnees/quetes.json + quest commands/conditions, donner_creature/combat_sauvage (legendaries), objet_requis on obstacles/water (no HMs), engine-tracked compteurs (captures, trainers beaten, evolutions) as shop conditions in donnees/boutiques.json (incl. creature buy/sell shop), item effets (nature/IV), ecran_ev command, level cap + trainer scaling settings in jeu.json. Battle evolution = engine only.
- Ragna's corrections (2026-10-20): tile size stays free per game; unlimited layers with profondeur (dessous/joueur/dessus), opacite, fusion (canvas composite names), parallaxe {x,y}; aesthetics matter.
- Tafl 0.6 = PR #22, merged 2026-10-20 with Ragna's yes. Implemented: tuiles/FORMAT.md (copied into each game folder by main game:write), doc.maps/mapIndex/map, map.passage Uint8Array codes 0 auto,1 libre,2 bloque,3-6 rebords bas/haut/gauche/droite, collisions computed on save (skip 'dessus' layers), zones {id,name,type,x,y,w,h,objet}, warps {id,x,y,carte,tx,ty,direction}, doc.depart; tile.passage; main IPC game:pick/open/find/register/write (gameFolders whitelist); App.options.layer -1 = passage row; tools zone Z, warp T, start J; Claude actions cartes/peindre_passage/passage_tuile/zone/teleporteur/depart/enregistrer_jeu.
- Tafl 0.7 = PR #23 (merged 2026-10-20 with Ragna's yes): renderer/events.js (Events: COMMANDES/CONDITIONS catalogs, normEvent, verifierPages, editEvent overlay z40, editData overlay), map.events (French JSON keys, last true page wins, local = self-switch, qui '@evenement'), doc.data {personnages (portraits dataURL by expression, single heros, couleur, tuile), quetes (etapes [{texte}], suivante, personnages), interrupteurs}; files donnees/*.json listed in jeu.donnees; tool event N; Claude actions evenement/personnage/quete/interrupteur/donnees. Creature/item/trainer/shop ids are free text until 0.8.
- Tafl 0.8 = PR #24 (merged 2026-10-20 with Ragna's yes, release tafl-v0.8.0): renderer/donnees.js (Donnees: SORTES types/talents/attaques/creatures/objets/dresseurs/boutiques/reglages, NATURES, tab defs for Events.editData left nav, fusionner import merge by `officiel`), officiel.js PokeAPI CSV import (IPC officiel:importer), zones rencontres+taux, map.ambiance {meteo,intensite,teinte,force} with stage preview, Claude actions voir_donnees/donnee/image_donnee/importer_officiel/ambiance. Next: engine tool + Jouer button; overworld character sprites not done yet.
