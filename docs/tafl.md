- Model: renderer/doc.js copy-on-write (tileForEdit/layerForEdit after Doc.begin); tools in stage.js work on a generic "grid" (tile pixels or map cells). Map cells store tile indices (remapped on delete/move).
- Testing: Playwright _electron under xvfb-run; mock native dialogs via electronApp.evaluate (no `require` in that context). Never `await page.evaluate()` a function that waits on an in-app dialog. A crashed test leaves Electron running and the single-instance lock makes the next launch hang. Stage must not start ResizeObserver at script load (App not defined yet): Stage.init() from App.init.
