- Name Saga + rune ᛃ (Jera) approved by Ragna ("ok") 2026-10-20. Folder atelier/moteur, package atelier-moteur, appId fr.ragna.saga, userData %APPDATA%\atelier-moteur, tag saga-v.
- Tech: Electron + plain Canvas 2D, no framework (like Tafl). Engine core (renderer/moteur/) reads only game file texts so it can later be exported as a web build.
- Saga 0.1 = PR #26 (2026-10-20, branch claude/project-thread-l7jqj0), with Tafl 0.9 (Jouer F5 / Maj+F5 from hovered cell, IPC jeu:jouer; clone Saga preferred when Tafl runs from clone) and Atelier 0.10 (outils.js entry, "Jouer dans Saga" on folders with jeu.json). Squash-merged 6cde4c3 on 2026-10-21 with Ragna's yes (releases saga-v0.1.0, tafl-v0.9.0, atelier-v0.10.0).
- CLI: Saga.exe <dossier> --carte= --x= --y= --direction= ; single instance reloads game. F5 reload keeps position, F3 debug overlay.
- Testing: Playwright + xvfb. Electron as root in container needs --no-sandbox, so Tafl→Saga spawn can't fully run there (fine on Windows). Captures: /mnt/project-files/saga/captures.
- PR #28 squash-merged ee9ceba 2026-10-21 with Ragna's yes (release saga-v0.2.0): 0.1.2 side-walk jitter fix (round player once, camera from that integer) + Saga 0.2.0 events: action key (Espace/Entrée/E, gamepad A), toucher/auto triggers, dialogue.js (portraits, choices, annonces), scripts.js (all FORMAT.md commands; combat/boutique/ecran_ev are placeholders, trainer battle counts as won), aleatoire/tourne NPCs, Tab carnet, saves in %APPDATA%\atelier-moteur\sauvegardes (Continuer/Nouvelle partie prompt).
- Character sprites (PR #31, tafl-v0.12.0 + saga-v0.2.1): personnage.sprite = { largeur, hauteur, images, planche PNG: 4 rows bas/gauche/droite/haut, col 0 = debout, then pas }. Walk: during step n, image 1+((n-1)%(images-1)) for first half, then 0. Feet at bottom of cell, taller sprites overflow up. Tafl editor in tuiles/renderer/sprites.js; Claude actions dessiner_sprite/voir_sprite, personnage action sprite. Saga draws sprite > perso tuile > bonhomme (event apparence.tuile wins). Ragna asked to keep advancing Saga after this (combat next).
- Saga 0.3 combat = PR #32 squash-merged e5109ee 2026-10-21 with Ragna's yes (release saga-v0.3.0): wild encounters + trainer battles, Gen3+ formulas, capture, XP/evolution in battle, defeat → dernierSoin. Rules isolated in moteur/renderer/moteur/regles/pokemon/ (creatures.js, combat.js); engine only calls the `Regles` facade (regles/regles.js: existe, creer, completer, soigner, resume, combattre). ecran-combat.js is rule-agnostic UI. Captures: /mnt/project-files/saga/captures-combat.
- Long-term direction (Ragna, 2026-10-21): Tafl and Saga must eventually support rules other than Pokémon. Keep Pokémon-specific logic behind replaceable rule modules, not wired everywhere. See [tafl-editeur-jeu](tafl-editeur-jeu.md).
- In-game UI themes (Ragna chose 2026-10-21): both "verre" (dark glassmorphism) and "pixel" (retro pixel font/frames), chosen per game in Tafl (reglages) with an accent color; Saga applies it to dialogues, combat, carnet. Fixes (Échap in combat, entry animations) + themes = PR #34 squash-merged fd22813 2026-10-21 with Ragna yes (saga-v0.4.0 + tafl-v0.15.0; reglages.interface {theme, accent}; pixel font Jersey 10 OFL in moteur/renderer/polices — Pixelify Sans rejected, its 5 looks like S).
